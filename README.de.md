# FTN-Coop Full · 0.1.1

## Deutsch

FTN-Coop Full ist eine inoffizielle Koop-Mod für die Steam-Kaufversion von Find The Needle. Ein Spieler hostet die Welt und kann bis zu drei Freunde einladen. Der gemeinsame Spielstand liegt beim Host.

Version **0.1.1** ist für Steam-App **5160800**, Build **26547680** vorgesehen. Alle Spieler brauchen denselben Spiel-Build und dieselbe Mod-Version. Die Demo hat ein [eigenes Projekt mit Downloads](https://github.com/GaleR-Tech/FTN-Coop).

### Installation und Spielstart

1. Spiel schließen. Unter Windows `FTN-Coop-Full-0.1.1-Setup.exe` starten. Beim ZIP zuerst entpacken und `Installieren.cmd` starten.
2. Den Steam-Spielordner prüfen und **Installieren** wählen. Unter Linux mit Steam Proton `python3 FTN-Coop-Full-0.1.1-Linux.run` ausführen. Für ein Terminal ohne Tk `--cli` anhängen.
3. Das Spiel über Steam starten. Eine Welt laden und mit **F2** eine private Sitzung starten. Freunde über das Steam-Overlay einladen.

Die Mod lässt sich über denselben Installer entfernen. Audio, Steuerung, Oberfläche, Anzeige und Grafik bleiben beim jeweiligen Spieler. Der Host gibt die Gameplay-Einstellungen vor, einschließlich der Staus durch Schrott.

### Prüfstand

Der lokale Test verwendet den echten Build der Kaufversion, getrennte Spielprofile und eine lokale Verbindung. Gäste können den originalen Baukatalog, Forschungsbaum und das Pausenmenü nutzen. Die neuen Menüs für Blaupausen, Produktion, Depot, Strom und Wasser brauchen noch eine Koop-Anbindung. Mitspieler erscheinen als einfache Figuren. Die neuen Körperanimationen und Emotes werden noch nicht synchronisiert. Internetpartien mit mehreren Steam-Konten und Proton mit Grafik stehen noch als Tests aus.
