# FTN-Coop Full · 0.2.0

## English

FTN-Coop Full is an unofficial co-op mod for the Steam purchase edition of Find The Needle. One player hosts a world and can invite up to three friends. The host keeps the shared save.

Version **0.2.0** targets Steam app **5160800**, build **26547680**. Everyone needs the same mod and game build. The demo has its own [project and downloads](https://github.com/GaleR-Tech/FTN-Coop).

### Install and play

1. Close the game. On Windows, run `FTN-Coop-Full-0.2.0-Setup.exe`. With the ZIP, extract it first and run `Install.cmd`.
2. Check the Steam game folder and choose **Install**. On Linux with Steam Proton, run `python3 FTN-Coop-Full-0.2.0-Linux.run`. Add `--cli` for a terminal without Tk.
3. Start the game through Steam. Load a world and press **F2** to start a private session. Invite friends through the Steam overlay.

The installer also removes the mod. Audio, control, interface, display and graphics preferences stay local. The host shares gameplay settings, including scrap jams.

### Verification

The local test uses the purchase build with isolated profiles. Guests use the native blueprint catalogue and can save a plan from a designer pad. Clearing a pad or loading a plan onto it requires the host. The native production, depot, power and water menus send changes to the host. The game displays each remote player with its original character and synchronizes movement and emotes. The emote wheel uses the game binding (Y by default on the tested layout). Internet play between separate Steam accounts and graphical Proton play still need dedicated tests.
