# Changelog / Änderungen

## 0.2.0 · Guest menus and emotes / Gastmenüs und Emotes

### English

- Remote players now use the game's character model with movement animations and synchronized emotes. Open the emote wheel with the game's binding. On the tested keyboard layout it was **Y**.
- Guests can select and place blueprints from their own catalogue and save new ones at a designer pad. Loading onto or clearing the pad requires the host.
- Guests can use the original production, depot, power and water menus. The host validates shared changes such as recipe changes, depot withdrawals and pump switches.
- Tested with four local game instances, including one graphical guest, on Steam build **26547680**. Internet play across separate Steam accounts and Proton gameplay still need testing. All players need mod version **0.2.0**.

### Deutsch

- Mitspieler erscheinen als Spielfiguren mit Bewegungsanimationen und synchronisierten Emotes. Das Emote-Rad öffnet sich über die Spielbelegung, im Test mit **Y**.
- Gäste können Blaupausen aus ihrem eigenen Katalog auswählen und platzieren sowie am Entwurfsplatz neue Vorlagen speichern. Vorlagen auf den Entwurfsplatz laden oder ihn räumen kann der Host.
- Gäste können die Originalmenüs für Produktion, Depot, Strom und Wasser nutzen. Der Host prüft gemeinsame Änderungen wie Rezeptwechsel, Depotentnahmen und das Schalten von Pumpen.
- Lokal mit vier Spielinstanzen geprüft, davon ein Gast mit Grafik. Unterstützt wird Steam-Build **26547680**. Internetpartien mit getrennten Steam-Konten und das Spielen unter Proton stehen noch als Tests aus. Alle Spieler brauchen Mod-Version **0.2.0**.

## 0.1.1 · Update check / Updateprüfung

### English

- The F2 update check uses the permanent GitHub repository ID. It works after a repository rename without following redirects.
- Download and project links point to the current public repository. The supported Steam build is 26547680.
- If you have 0.1.0, download 0.1.1 from GitHub and install it manually. Restart the game after updating. Everyone in the session needs the same mod version.

### Deutsch

- Die Updateprüfung im F2-Menü nutzt die feste GitHub-Repository-ID. Sie funktioniert auch nach einer Umbenennung, ohne Weiterleitungen zu folgen.
- Die Download- und Projektlinks führen zum aktuellen öffentlichen Repository. Unterstützt wird Steam-Build 26547680.
- Wer 0.1.0 nutzt, lädt 0.1.1 manuell von GitHub herunter und startet das Spiel nach dem Update neu. Alle in der Sitzung brauchen dieselbe Mod-Version.

## 0.1.0 · Full game / Kaufversion

### English

- Target Steam purchase app 5160800 and build 26547680. The installer detects the matching Steam manifest and preserves the game's existing rendering configuration.
- Use the purchase edition's native build tool and hotbar paging. A guest can change pages without a host update switching their current page.
- Show the host's quest checklist on guests. Refresh the native depot, buyer and case-goal displays when their shared state changes.
- Share the host's scrap-jam setting. Restore guest save-mode flags and gameplay settings on departure.

### Deutsch

- Unterstützt Steam-App 5160800 und Build 26547680 der Kaufversion. Der Installer prüft das zugehörige Steam-Manifest und bewahrt die vorhandene Grafik-Konfiguration des Spiels.
- Nutzt das originale Bauwerkzeug und die Schnellleisten-Seiten der Kaufversion. Gäste behalten ihre gewählte Seite bei Updates vom Host.
- Zeigt Gästen die Quest-Checkliste des Hosts an. Depot, Käufer und Schrankziel werden bei Änderungen aktualisiert.
- Übernimmt die Einstellung für Staus durch Schrott vom Host. Beim Verlassen stellt die Mod die vorherigen Spielstand-Modi und Gameplay-Einstellungen des Gasts wieder her.
